Après une révocation, publiez le registre (onglet « Registre GitHub ») : l'application bloque la licence à sa prochaine connexion à Internet.

Code de réinitialisation du mot de passe

Le client a oublié son mot de passe : demandez l'identifiant affiché sur son écran (« Mot de passe oublié ? »). Le code est valable 7 jours, uniquement sur cet appareil.

Registre public sur GitHub

Le fichier licenses/registry.json du dépôt liste les licences et celles qui sont révoquées. L'application le consulte quand elle a Internet. Les noms des clients et les téléphones n'y figurent pas : ils restent dans ce navigateur.

Sauvegarde

La liste des clients est enregistrée dans ce navigateur. Téléchargez une sauvegarde régulièrement et gardez aussi le fichier de la clé privée en lieu sûr.
